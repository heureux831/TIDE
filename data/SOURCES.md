# Data sources and boundaries

The mandatory overnight experiment uses only the deterministic fictional
profiles generated by `tide build-data`. The committed `data/raw/sources.jsonl`
and `data/frozen/sources.jsonl` contain no downloaded conversations and no real
user records.

`tide-download-data` supports small, ignored samples for later extensions:

- HealthBench: OpenAI `simple-evals` public JSONL, recorded as MIT-licensed by
  its source repository.
- WildChat: `allenai/WildChat` on Hugging Face, whose dataset card declares
  ODC-BY and describes its de-identification process.

Every download writes a sibling manifest with the URL/repository, selection
rule, record count, timestamp, SHA256, and an explicit marker that the sample is
not used by the controlled feasibility run. Review current upstream terms before
redistributing downloaded records.
